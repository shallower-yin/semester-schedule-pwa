# 使用说明

## 初次使用

1. 普通事项可直接创建；需要课程表时再创建学期，开学日期填写第一教学周的星期一。
2. 在“设置 → 每日时间块设置”中分别调整周一至周日作息，可增删节次、午休和其他休息。
3. 在“日程 → 新增日程”中选择课程、临时事项或习惯。
4. 在日程空白处点击，可按对应时段创建临时事项；如果把结束日期设为后续日期，中间每一天同一时间段都会显示该事项。
5. 如需导入学校课表，进入“设置 → 课表提取器”，选择天津大学及学校导出的 `.xls` 文件，并按提示选择合并、替换或追加。
6. 在“设置 → 数据备份”中保存和下载 JSON 备份。

## 手机使用

- 底部导航可在“设置 → 底部按钮设置”中自行选择显示哪些入口和顺序；未显示入口仍可从左上角菜单进入。
- 日程页右下角蓝色圆形按钮用于快速新增日程。
- 手机使用七日周课表，可点选日期；使用周切换按钮查看其他周。
- 手机周课表可长按空白时间格快速新增事项；同一时段的重叠安排可点击展开选择。
- 表单弹窗在手机上以底部抽屉显示，保存按钮固定在底部区域。

## 账号、同步和提醒

- 登录同一个邮箱账号后，手机和电脑通过 Supabase 同步数据。
- 登录或启动应用、从后台回到前台、恢复联网时会自动同步；本机待上传数量变化后约 1.5 秒自动同步，也可点击“立即同步”。每轮先上传本机变更，再拉取云端数据。
- 常规同步先比对云端记录的 ID 和版本，只下载新增或变化的内容，通过完整 ID 清单识别另一台设备的删除。本机没有缓存、手动“重新拉取云端”或清理旧版删除标记时会完整下载。
- 无网时可以继续查看和编辑，恢复联网后补传。持续停留在前台时没有固定间隔拉取云端的轮询。
- “账号与同步”里可以查看待上传数量、同步失败原因、通知订阅状态，并可手动重新拉取云端。
- 事项、习惯和纪念日提醒分两类：应用打开时每 30 秒本地检查；应用关闭后由 Supabase Edge Function 按服务端定时任务派发 Web Push，当前任务间隔为 2 分钟。浏览器和系统通知权限必须都允许，错过 15 分钟以上的提醒不会补发。
- 课程可在编辑窗口中单独开启提醒并设置提前时间，按实际教学周和上课节次提醒，停课日期会跳过。点击通知可打开对应课程；Android 安装包使用系统本地提醒。

## 快捷入口

- 顶部搜索按钮可以跨模块查找并直接打开记录。
- 顶部按钮可在“设置 → 顶部按钮设置”中选择显示哪些工具和顺序；手机底部入口仍在“设置 → 底部按钮设置”中单独管理。
- 顶部快速录入按钮或新增日程中的“快速录入”可用一句话创建事项。支持示例：`今天 18点30 写实验报告`、`明天 9:00 交作业`、`后天 20点 背单词`、`这周五 14:30 开组会`、`下周一 8点10 上机测试`、`7月18日 19:00 看电影`。
- 键盘 `/` 打开全局搜索，`A` 打开本地日程助手，`D` 打开 AI 助手，`M` 打开思维导图，`Q` 打开快速录入，`N` 新增今天事项，`T` 回到今天页，`Esc` 关闭当前弹窗。
- “日程助手”是本地规则问答，不会把日程发送给外部 AI。可问：`今天有什么安排？`、`明天有哪些未完成事项？`、`这周五下午有什么课？`、`高数在哪个教室？`、`最近有哪些逾期事项？`、`这周完成率多少？`、`最近 7 天专注了多久？`、`明天有冲突吗？`
- “AI 助手”可根据当前日程摘要回答安排、冲突、未完成事项和时间规划问题；也能按明确指令创建事项、习惯、纪念日、生日、节日和备忘录。选择支持附件的模型时，还可导入图片、PDF、DOCX、TXT、Markdown 和 CSV。
- “管理后台”只对管理员账号显示，可切换 DeepSeek、Xiaomi MiMo、SiliconFlow、TJU 等代码支持的提供商和模型；MiMo 的按量 API 与 Token Plan 使用相互独立的通道和凭据。设置保存在数据库中并从下一次 AI 请求起生效；同时可修改普通用户和会员的日/周额度并管理单个账号权限，管理员不限额。
- “今天”页可以把未完成事项标记完成，或快速推迟到明天、周末和指定日期。
- “设置 → 统计与日历导出”可查看完成率并导出 ICS；“设置 → 数据健康检查”可处理重复分类和异常事项。
- “账号与同步”里可以查看提醒诊断步骤，并创建 1 分钟后的真实提醒测试。
